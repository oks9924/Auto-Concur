# 사용자 확인 입력 범위 — 7종

자동 조사 도구 결과가 아니라 사용자가 직접 지정한 업무 입력 범위다.

| 유형 | 작업지 안내 / 반영 범위 |
|---|---|
| 내부 직원간 식음료 | 기존 안내와 기본 참석자 자동 입력 유지 |
| 대중교통비 | 코멘트(Concur의 설명)만 안내/내용 반영 |
| 업무 및 영량 향상관련 교육비 | 설명만이라는 규칙 등록. 실제 이름/코드 연결은 미완료 |
| 항공비 | 코멘트(설명)만 안내/내용 반영 |
| 숙박비 | 기존 안내/숙박 처리 유지 |
| 주차비 | 코멘트(설명)만 안내/내용 반영 |
| 기타 사무용품(문구류 등) | 코멘트(설명)만 안내/내용 반영 |

`GREEN_BY_TYPE`와 `input_guide()`가 표/상세 편집의 초록색 안내를 제공한다.
`description_only()`를 기존 Plan이 사용하므로 위 5종은 계획에서 목적/참석자/숙박 입력을 제외한다.
경비유형 변경, 영수증 첨부 절차는 유지한다. 기존 작업지의 다른 칸을 삭제하지 않는다.
빈 설명은 기존 Concur 값을 유지하며 이번 변경에서 별도 필수값 차단을 추가하지 않는다.
다른 경비유형을 드롭다운에서 삭제하지 않는다.

## 교육비 연결 대기

`업무 및 영량 향상관련 교육비`는 사용자 메시지 표기를 그대로 기록했다.
실제 화면 표기인지 오타인지는 확정하지 않았고, 알려진 코드도 없다.
기본 경비유형 목록에는 이 유형이 없으므로 기본 설치에서 선택/자동 변경이 지원된다고 볼 수 없다.
실제 이름과 계정의 유형 코드 확인 후 settings에 연결해야 한다. 추측 코드/유사한 다른 교육비를 사용하지 않는다.

## 변경/검증 범위

업무 정책 파일과 관련 단위 테스트/문서만 변경한다. 달력, 참석자 자동 채움 구현,
Concur DOM 탐색/저장 함수, 파일 형식은 변경하지 않는다. 실제 Concur 계정 실행/EXE 빌드는 하지 않는다.
