# 내부 직원간 식음료 선택 시 기본 참석자

홈에서 기본 참석자를 입력한 뒤 작업지를 연다. 경비유형을 다른 유형/빈칸에서
`내부 직원간 식음료`(코드 01182)로 변경할 때 참석자 칸이 비어 있으면 기본 참석자를 채운다.
이미 참석자가 있거나 같은 편집에서 참석자를 직접 입력하면 그 값을 보존한다.
추가 참석자는 변경하지 않는다. 기본 참석자가 비어 있으면 아무것도 넣지 않는다.

- 표의 직접 편집·드롭다운·붙여넣기·여러 행 유형 변경에 적용한다.
- 한 건 상세 편집에서는 유형 선택 즉시 참석자 입력칸에 표시한다.
- 표에서는 유형 변경과 자동 채움을 Ctrl+Z 한 번으로 함께 되돌리고 다시 실행할 수 있다.
- 상세 편집에서 자동 입력 후 이름을 지우거나 수정하면 사용자의 최종 입력을 그대로 적용한다.
- 기존 작업지 열기·불러오기·복원·저장·Concur 반영 시점에는 빈 참석자를 자동 보충하지 않는다.
- 이미 내부 직원간 식음료인 행의 참석자를 비워도 다른 셀 편집이나 재열기로 다시 채우지 않는다.
- 다른 경비유형으로 바꾸더라도 기존 참석자를 임의로 삭제하지 않는다.
- 홈의 기본 참석자를 변경해도 기존 작업지 전체를 소급 변경하지 않는다.

자동 채움은 프로그램의 편집 단계이며, Concur에는 저장 후 반영을 실행할 때만 전달된다.
목록 매칭·Concur 저장 로직·작업지 파일 형식은 변경하지 않는다.
테스트는 합성 거래와 Tk/tksheet 화면을 사용하며 실제 Concur 계정에 접속하지 않는다.
